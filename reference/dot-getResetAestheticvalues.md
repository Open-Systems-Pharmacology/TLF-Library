# .getResetAestheticvalues

Get the aesthetic values (e.g color, shape, linetype) from an aesthetic
map defined in `Theme`. Reset the value every time it is used.

## Usage

``` r
.getResetAestheticvalues(n, map)
```

## Arguments

- n:

  integer defining size of returned aesthetic vector

- map:

  Aesthetic (e.g. color, shape, linetype) map from `Theme` object.

## Value

Vector of aesthetics
