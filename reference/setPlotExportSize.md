# setPlotExportSize

Set plot export properties

## Usage

``` r
setPlotExportSize(
  plotObject,
  width = NULL,
  height = NULL,
  units = NULL,
  dpi = NULL
)
```

## Arguments

- plotObject:

  Graphical object created from ggplot

- width:

  plot width in `unit`

- height:

  plot height in `unit`

- units:

  units of `width` and `height`

- dpi:

  numeric value defining plot resolution (dots per inch)

## Value

ggplot object with updated labels
