# .setDataMapping

Set `DataMapping` object internally using `tlf` default if `dataMapping`
is not provided

## Usage

``` r
.setDataMapping(dataMapping, DataMappingClass, data = NULL)
```

## Arguments

- dataMapping:

  A `DataMappingClass` object

- DataMappingClass:

  Required class for `dataMapping`

- data:

  A data.frame potentially used for smart mapping

## Value

A `DataMapping` object
