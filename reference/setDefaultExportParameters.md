# setDefaultExportParameters

Set default tlf properties for exporting/saving plots

## Usage

``` r
setDefaultExportParameters(
  format = NULL,
  width = NULL,
  height = NULL,
  units = NULL,
  dpi = NULL,
  name = NULL
)
```

## Arguments

- format:

  file format of the exported plots

- width:

  plot width in `unit`

- height:

  plot height in `unit`

- units:

  units of `width` and `height`

- dpi:

  units of `width` and `height`

- name:

  base file name of the exported plots
