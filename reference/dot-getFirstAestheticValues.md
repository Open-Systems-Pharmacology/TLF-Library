# .getFirstAestheticValues

Get the next aesthetic values (e.g color, shape, linetype) from an
aesthetic map defined in `Theme`

## Usage

``` r
.getFirstAestheticValues(n, map)
```

## Arguments

- n:

  integer defining size of returned aesthetic vector

- map:

  Aesthetic (e.g. color, shape, linetype) map from `Theme` object.

- position:

  integer defining at which position to look for aesthetic vector

## Value

Vector of aesthetics
