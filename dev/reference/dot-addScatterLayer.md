# .addScatterLayer

Add scatter points layer of a molecule plot

## Usage

``` r
.addScatterLayer(plotObject, data, mapLabels)
```

## Arguments

- plotObject:

  A `ggplot` object

- data:

  A data.frame with labels mapped to properties and obtained from a
  `DataMapping` object

- mapLabels:

  List of mapped label names passed to
  [`ggplot2::aes`](https://ggplot2.tidyverse.org/reference/aes.html)

## Value

A `ggplot` object
