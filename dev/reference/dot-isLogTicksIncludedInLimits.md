# Check that at least one log tick is included in limits

Check that at least one log tick is included in limits

## Usage

``` r
.isLogTicksIncludedInLimits(limits, scale)
```

## Arguments

- limits:

  An array of numeric values

- scale:

  Name of log scale: `Scaling$log` for log10 scale, `Scaling$ln` for
  logarithmic scale
