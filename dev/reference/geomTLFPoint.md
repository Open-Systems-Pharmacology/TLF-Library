# geomTLFPoint

geom similar to
[`geom_point()`](https://ggplot2.tidyverse.org/reference/geom_point.html)
but that leverage fonts to draw its shapes

## Usage

``` r
geomTLFPoint(
  mapping = NULL,
  data = NULL,
  stat = "identity",
  position = "identity",
  na.rm = FALSE,
  show.legend = NA,
  inherit.aes = TRUE,
  ...
)
```

## Arguments

- mapping:

  mapping from `ggplot2` package as provided by
  [`aes()`](https://ggplot2.tidyverse.org/reference/aes.html)

- data:

  data.frame

- stat:

  stat name from `ggplot2`

- position:

  position name from `ggplot2`

- na.rm:

  a logical value indicating

- show.legend:

  = NA,

- inherit.aes:

  a logical value indicating if aesthetics are inherited

- ...:

  other arguments.
