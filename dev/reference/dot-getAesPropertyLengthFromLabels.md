# .getAesPropertyLengthFromLabels

Get the names of the variables mapped to aesthetic properties

## Usage

``` r
.getAesPropertyLengthFromLabels(data, columnNames, propertyNames)
```

## Arguments

- data:

  A data.frame with labels mapped to properties and obtained from a
  `DataMapping` object

- columnNames:

  List of mapped column names of `data` obtained

- propertyNames:

  Names of aesthetic property (e.g. `"color"`, `"shape"`...)

## Value

A list of variable names
