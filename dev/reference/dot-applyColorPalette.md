# .applyColorPalette

Apply a color palette to a ggplot object

## Usage

``` r
.applyColorPalette(plotObject, colorPalette = NULL)
```

## Arguments

- plotObject:

  A `ggplot` object

- colorPalette:

  A color palette name. See enum `ColorPalettes` to get available color
  palettes.

## Value

A `ggplot` object
