# isBetween

Assess if `x` is between `left` and `right` bounds. Shortcut for
`x >= left & x <= right` if `strict=FALSE` (default). Shortcut for
`x > left & x < right` if `strict=TRUE`.

## Usage

``` r
isBetween(x, left, right, strict = FALSE)
```

## Arguments

- x:

  Numeric values to assess

- left:

  Numeric value(s) used as lower bound

- right:

  Numeric value(s) used as upper bound

- strict:

  Logical value defining if `x` is strictly between `left` and `right`.
  Default value is `FALSE`.

## Value

Logical values
