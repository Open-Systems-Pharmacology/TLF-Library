# .dataMappingLabel

Get label with unit based on mapping

## Usage

``` r
.dataMappingLabel(mapping = NULL, metaData = NULL)
```

## Arguments

- mapping:

  Variable name in `data` and `metaData` to get label from

- metaData:

  List of information about `data` including `dimension` and `unit`

## Value

Label as `dimention [unit]` from the mapping of the variable name
